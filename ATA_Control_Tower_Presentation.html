01 · The business process

Every shipment Under Clearance needs a correct ETA and ATA in the Hub

Before MANUAL

  • Open the Logistics Hub and filter Under Clearance, page by page
  • For each row, find the carrier and open its tracking website
  • Type the air waybill or bill of lading, read the dates by eye
  • Go back to the Hub, open Manage, type ETA (COE view) and ATA (BU view)
  • Save, and hope nothing was mistyped — no proof kept

After CONTROL TOWER

  • Reads every Under Clearance row in the Hub automatically
  • Picks the right carrier site (K-references go to DHL)
  • Reads ETA / ATA from the carrier's own page and keeps the page text
  • Writes COE ETA and BU ATA, then reloads and verifies the saved value
  • Screenshot evidence for every write; failures explained, never guessed

07 · ATLAS, the tower's assistant

Local AI, built in-house at Mantrac — no external API

💬
Ask in plain words

"Why did 8842001173 fail?" — answered from the run's own records, in English or Arabic. Runs locally inside Mantrac; no external AI service, no data leaves.

🩺
Diagnoses failures

Every failure is classified, with a root cause marked as fact or hypothesis and a recovery plan.

🔁
Self-healing, safely

Re-tests a stopped PO job in a sandbox. A fix counts as learned only after it is verified.

🙋
Human Action queue

Security checks wait for a person with "Open & Continue"; the run carries on meanwhile.

🌐
Private web search

Its own private search engine inside Mantrac, for questions like "is the carrier site down today?"

🥔
Potato Mode

A small joke when one shipment keeps failing, and a harvest when it is finally fixed. Morale matters.

08 · Control and safety

Built to stop safely, not to finish at any cost

✅
Verify every write

Each ETA/ATA is re-read from the Hub after saving, with a screenshot.

🛑
Fail closed

Missing, ambiguous or malformed data stops the job and says why.

🔐
Security checks stay human

CAPTCHAs are never solved, typed or stored by the software.

✉️
No email without a name

One send per named authorisation, bound to sender, recipient and file fingerprint.

🧾
Full audit trail

Hash-chained events: who, what, when, and the evidence behind it.

🔑
Private by design

Access key for the dashboard; no passwords or tokens ever logged.
