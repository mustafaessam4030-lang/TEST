Drop the track and artwork here:

  lilith.mp3   (any of .mp3 .m4a .ogg .wav .flac)
  cover.jpg    (any of .jpg .jpeg .png .webp)

The player picks up the first audio file and the first image file it finds.
Titles are fixed to Lilith / Saint Avangeline / Gardener of Eden.
If no audio file is present the player stays disabled and the dashboard
works normally.
