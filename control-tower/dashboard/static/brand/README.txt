OFFICIAL MANTRAC LOGO
=====================

Put the official Mantrac logo file here, named:

    mantrac-logo.svg      (preferred — sharp at every size)
    mantrac-logo.png      (used if there is no .svg; ~52px tall or more)

The dashboard's top-left brand slot loads it from /static/brand/ and shows it
28px tall. The wide Mantrac | CAT lockup (yellow band, black CAT block) fits:
crop it to the band itself — no white margin — and it shows ~112px wide.
When the logo is present the "MANTRAC" text beside it is hidden, since the
logo already says it; "ATA CONTROL TOWER" stays. Until a file is present the slot shows a dashed "Logo" placeholder.

Use the official asset as supplied by Mantrac. The dashboard does not draw,
trace or recolour the logo.
