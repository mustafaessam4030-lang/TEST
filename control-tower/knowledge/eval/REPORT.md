## What this does and does not show

- It checks retrieval, required and forbidden content, exact calculations, declining out-of-scope and run questions, and that answers carry their status and sources.
- **This score is optimistic.** The set was written alongside the engine and used to find its gaps (several were fixed because of it), so it is in-sample. The real measure is a held-out set written by Mantrac's logistics staff, in their own words; add it as eval_v2.json and run it unchanged.
- It does not grade free-form reasoning: ATLAS's knowledge answers are composed from the knowledge items' text and deterministic calculations, not generated, so a pass means the right knowledge was found and stated — not that ATLAS 'understands' logistics like an expert.
- Retrieval is keyword-based (BM25 with synonyms and Arabic folding). There is no embedding model in this platform; questions worded far from an item's words can miss it.
- No item is yet approved by a Mantrac reviewer; answers say so.
